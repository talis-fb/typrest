Typrest is an HTTP service that validates JSON payloads, renders [Typst](https://typst.app/)
templates, and returns PDF bytes. New to it? Start with the quick start.

## Reference

The **specifications** are the contract: each requirement has a stable ID such as `REQ-HTTP-020`
that the code and tests cite. The **architecture** pages describe how Typrest is built today.
Both are published from the <a href={`${REPO_URL}/tree/${REPO_BRANCH}/docs`}><code>docs/</code></a>
folder of the repository.
