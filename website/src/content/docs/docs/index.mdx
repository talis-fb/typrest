Typrest is a small server that makes PDFs. You design a document once as a template, run Typrest
next to your applications, and from then on any of them can get a finished PDF by sending the
document's data as JSON.

It is built for the documents every business system ends up producing: invoices, receipts,
reports, letters, certificates, tickets, and labels.

## How it works

1. **You write templates.** A template is a folder with a [Typst](https://typst.app/) file that
   describes the document: its layout, fonts, tables, and where each piece of data goes.
2. **You run Typrest.** It reads your templates folder, checks that every template works, and
   starts listening for requests. Each template gets its own address, such as `/invoice`.
3. **Your systems send JSON.** A request with the data for one document comes back as that
   document, as a PDF.

```bash
curl -X POST http://127.0.0.1:8080/invoice \
  -H 'Content-Type: application/json' \
  --data '{"number": "INV-0142", "customer": {"name": "Lumen Robotics"}}' \
  --output invoice.pdf
```

## Why people choose it

- **The documents look good.** Typst is a real typesetting system, so pages, tables, and fonts
  come out the way a designer expects, without a headless browser.
- **Every language can use it.** Typrest speaks HTTP and JSON, so there is no library to install
  in your application.
- **It is quick to set up.** Typrest is one program, or one Docker image, with no database.
- **It fails early.** A template with a mistake stops Typrest from starting, and incomplete data
  is refused with a message that names the field.
- **It stays on your machines.** Typrest is open source and self-hosted.
