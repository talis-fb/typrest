# `papelon.toml` Specification

## Goal

`papelon.toml` defines the root configuration for a Papelon project in filesystem mode.

In the MVP, it exists to answer one question:

Which directory contains the project templates?

---

## File Location

The file name is always:

```text
papelon.toml
```

It lives at the project root.

Example:

```text
project/
  papelon.toml
  templates/
```

---

## Format

The file format is TOML.

Example:

```toml
schema_version = "v1"
templates_root = "templates"
```

---

## Top-Level Fields

```text
papelon.toml
 ├── schema_version (string, required)
 └── templates_root (string, required)
```

Unknown top-level fields should be ignored in the MVP so the format can evolve without breaking older binaries.

---

## `schema_version`

Type:

```text
string
```

Required:

```text
yes
```

Supported values:

- `v1`

Responsibility:

Declares which `papelon.toml` format version is being used.

Rules:

- The field must exist.
- The value must be a string.
- The only supported value in the MVP is `v1`.
- Missing or unsupported values must produce a configuration load error.

---

## `templates_root`

Type:

```text
string
```

Required:

```text
yes
```

Responsibility:

Defines the directory that contains template folders.

Example:

```toml
schema_version = "v1"
templates_root = "templates"
```

### Resolution Rules

- The path is resolved relative to the directory containing `papelon.toml`.
- Absolute paths are not allowed in the MVP.
- The normalized resolved path must stay inside the project root.

Valid example:

```toml
templates_root = "templates"
```

Valid example:

```toml
templates_root = "./templates"
```

Invalid example:

```toml
templates_root = "/srv/templates"
```

Invalid example:

```toml
templates_root = "../shared-templates"
```

### Runtime Rules

After resolution:

- the path must exist
- the path must be a directory

Otherwise the CLI must fail before starting the server.

---

## Default File Generated By `papelon init`

`papelon init` must generate:

```toml
schema_version = "v1"
templates_root = "templates"
```

This creates the standard convention:

- config at the project root
- templates under `./templates`

---

## Non-Goals For This Spec

This file does not currently define:

- server port
- watch settings
- store backends
- authentication
- per-template overrides
- environment-specific configuration

If those are added later, this specification must be updated first.
